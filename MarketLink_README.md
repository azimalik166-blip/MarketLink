# MarketLink
**Fresh Food, Fair Trade**

## 1. Project Overview

MarketLink is a browser-based farmers marketplace that connects customers with local farmers and physical markets.

Customers can:
- Register and log in
- Browse, search, and filter products
- View product, farmer, and market details
- Add products to a cart
- Select a pickup market, date, and available time slot
- Place pickup reservations
- View order details and order history
- Track order status
- Manage favourites and saved markets
- Submit and view product reviews
- Compare products
- View recently viewed and recommended products
- Reorder eligible previous purchases
- Modify supported orders
- Receive in-app notifications
- Access order receipts and supported CSV exports

Farmers can:
- Access the Farmer Studio
- Manage their own products
- Update product information and stock
- Mark products as sold out
- Manage weekly stock templates
- Configure supported pickup availability
- View incoming orders
- Update order status
- Manage farmer-related market and pickup information supported by the application
- Receive relevant notifications

Administrators can:
- Access the Admin Dashboard
- View platform statistics
- Manage users and account status
- Manage markets
- Manage products and categories through supported administrative actions
- View recent orders
- Review activity/audit information
- Manage supported announcements and platform data

**Payment model:** Orders are reserved online and paid in cash at pickup. No online payment gateway is included.

## 4. How to Run

### Option A — Laravel Development Server

Open PowerShell/Command Prompt inside the `MarketLink` project folder.

Install PHP dependencies:

```bash
composer install
```

Create the environment file:

```bash
copy .env.example .env
```

Generate the Laravel application key:

```bash
php artisan key:generate
```

Create a MySQL database, then configure the database values in `.env`:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=marketlink
DB_USERNAME=root
DB_PASSWORD=
```

Run the migrations:

```bash
php artisan migrate
```

Seed the database if demo/seed data is required:

```bash
php artisan db:seed
```

Start the Laravel server:

```bash
php artisan serve
```

Then open:

```text
http://127.0.0.1:8000
```

### Option B — XAMPP

1. Install/start XAMPP.
2. Start Apache.
3. Start MySQL.
4. Create a MySQL database named `marketlink`.
5. Copy the project into your local development directory.
6. Open the project folder in PowerShell/Command Prompt.
7. Run `composer install`.
8. Configure the `.env` file.
9. Run `php artisan key:generate`.
10. Run `php artisan migrate`.
11. Run `php artisan db:seed` when demo data is required.
12. Start the application using:

```bash
php artisan serve
```

For an Apache deployment, configure the web server so the Laravel `public` directory is the document root. Do not expose the project root or `.env` file directly through the web server.

# 8. Order Statuses

| Placed | Reservation has been created |

| Ready | Order is ready for collection |

The exact transitions available to a user depend on the application's authorization and order-management rules.

# 11. Core Modules

Registration, login, logout, session management, password hashing, account status checks, role protection, password reset, and supported email OTP verification.

Product listing, search, filtering, categories, product details, stock information, prices, farmer information, product comparison, recommendations, and recently viewed products.

Farmer profiles, stall information, farmer products, product management, incoming orders, stock management, and Farmer Studio functionality.

Farmers can use weekly stock templates to support recurring stock planning and management.

Customers can save preferred markets for easier access.

The project includes an application assistant for supported MarketLink questions and workflows. Its capabilities depend on the implemented assistant logic and available application data; it should not be treated as an unrestricted general-purpose AI model.

Supported administrative actions and important platform events can be recorded for activity tracking and auditing.

### Email / Password OTP
The project includes services and data structures for supported email notifications and password-reset OTP workflows. Correct SMTP/mail configuration is required when these features are enabled.

# 16. Troubleshooting

### Website does not start

Check PHP:

```bash
php -v
```

Check Composer:

```bash
composer -V
```

Install dependencies:

```bash
composer install
```

Generate the application key:

```bash
php artisan key:generate
```

Start Laravel:

```bash
php artisan serve
```

Then visit:

```text
http://127.0.0.1:8000
```

### Database error

If using MySQL:

1. Start MySQL from XAMPP.
2. Confirm the `marketlink` database exists.
3. Check `.env` database configuration.
4. Confirm username and password.
5. Run:

```bash
php artisan migrate
```

If the database schema is incomplete:

```bash
php artisan migrate:fresh --seed
```

> `migrate:fresh --seed` deletes existing database tables/data before recreating them. Use it only when resetting development/demo data.

### Composer dependency error

Run:

```bash
composer install
```

If the project dependencies are already installed but autoloading is inconsistent:

```bash
composer dump-autoload
```

### APP_KEY error

Run:

```bash
php artisan key:generate
```

### Login does not work

Check:
- User exists in the database
- Email is correct
- Password is correct
- Account status is active
- Correct role is assigned
- Database connection is working
- Sessions are functioning
- `.env` configuration is correct

### Maps do not appear

Check:
- Internet connection
- Browser console
- Leaflet resources
- OpenStreetMap tile access

### Email / OTP does not work

Check:
- Mail configuration in `.env`
- SMTP host
- SMTP port
- SMTP username
- SMTP password
- Sender address
- Mail encryption/settings
- Application logs

Do not publish real SMTP passwords or API credentials in this README.
