# Manual acceptance checklist

Customer:
- Login in light and dark mode.
- Explore -> Add to cart -> refresh -> cart still contains item.
- Update quantity / remove / clear.
- Checkout -> choose date -> slot list changes to that date.
- Place order -> stock decreases and farmer notification appears.
- Complete an order as farmer -> customer review form appears.

Farmer:
- Dashboard
- Product stock
- Pickup slots
- Accept / decline / ready / complete / cancel
- Review replies

Admin:
- Dashboard cards do not create blank stretched panels.
- Footer spans the viewport width.
- Users, markets, categories, moderation, announcements, reports.

Responsive:
- 390px mobile width
- 768px tablet width
- Desktop
